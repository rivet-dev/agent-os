# Archived browser implementation

The Rust crates, TypeScript packages, playground, and browser-only build tools
under this directory are retained as historical reference only.

They are not Cargo or pnpm workspace members and are not built, tested,
published, or supported. Their manifests, scripts, and internal paths
intentionally preserve the dependencies and workspace assumptions they had
when archived.

A future browser implementation is expected to be greenfield. Useful protocol,
kernel, transport, and worker ideas may be consulted here, but this code is not
a compatibility target or migration source.
